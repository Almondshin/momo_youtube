Momo Uploader

아기토끼 모모 / Momo the Bunny — YouTube channel publishing tool

개인정보처리방침 · Privacy Policy서비스 약관 · Terms

Momo Uploader는 유아용 교육 애니메이션 채널 "아기토끼 모모 (Momo the Bunny)"의 운영자가 자기 채널에 완성된 영상을 올릴 때 쓰는 내부 도구입니다. YouTube Data API v3 로 영상 업로드, 썸네일 설정, 재생목록 추가만 합니다.

Momo Uploader is an internal tool used by the operator of the kids' educational animation channel "Momo the Bunny" to publish finished episodes to that operator's own YouTube channel. It only uses the YouTube Data API v3 to upload videos, set thumbnails and add videos to playlists.

누가 쓰나요 · Who uses it

채널 운영자 본인만 씁니다. 일반 사용자 로그인, 회원가입, 시청자 데이터 수집 기능은 없습니다.
Only the channel operator. There is no public sign-in, no sign-up and no collection of viewer data.
