1. 접근하는 데이터 · Data we access

Momo Uploader 는 채널 운영자가 Google OAuth 로 허용한 범위 안에서 운영자 본인의 YouTube 채널에만 접근합니다. 사용하는 권한: youtube.upload(영상 업로드), youtube(썸네일 설정·재생목록 추가· 채널 이름 확인).

Momo Uploader accesses only the operator's own YouTube channel, within the scopes the operator grants through Google OAuth: youtube.upload (upload videos) and youtube (set thumbnails, add to playlists, read the channel name to confirm the connection).

2. 수집하지 않는 것 · What we do not collect

시청자, 아동, 다른 구글 사용자의 개인정보를 수집·저장·분석하지 않습니다. 쿠키·광고 추적·분석 도구를 쓰지 않습니다.
We do not collect, store or analyse personal data of viewers, children or any other Google users. We use no cookies, ad tracking or analytics.

3. 보관 · Storage

OAuth refresh token 은 GitHub 저장소의 암호화된 Secrets 에만 보관되고, 업로드 작업을 실행할 때만 쓰입니다. 제3자에게 제공·판매하지 않습니다. 업로드 결과로 영상 ID·URL 만 기록합니다.
The OAuth refresh token is kept only in encrypted GitHub repository Secrets and is used only when an upload job runs. It is never shared with or sold to third parties. Only the resulting video IDs and URLs are recorded.

4. Google API 정책 · Google API policies

Google API 로 받은 정보의 사용·이전은 Google API Services User Data Policy (Limited Use 요건 포함)를 따릅니다. 이 도구는 YouTube API Services 를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy also apply.

5. 권한 철회 · Revoking access

언제든지 Google 계정 → 보안 → 서드 파티 액세스에서 Momo Uploader 의 권한을 해제할 수 있습니다. 해제하면 저장된 토큰은 더 이상 동작하지 않습니다.
Access can be revoked at any time at Google Account → Security → Third-party access. The stored token then stops working.

6. 아동 · Children

채널의 영상은 아동용(made for kids)으로 표시되어 게시됩니다. 이 도구는 아동으로부터 어떤 정보도 수집하지 않습니다.
Videos are published as made for kids. This tool collects no information from children.
