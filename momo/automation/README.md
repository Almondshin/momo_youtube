## 남은 조건

Suno 공식 audio-download 도구는 `requires_credit` 응답 후 사용자의 승인을 받은 경우에만 `confirm=true`를 허용한다. 전체 자동화 희망을 특정 미래 다운로드 응답에 대한 승인으로 임의 기록하지 않는다. 로컬 예약 세션에서 Higgsfield 구독 도구 접근, YouTube 장기 인증·실제 공개 전환, 실행 결과 알림도 검증해야 한다. 이 조건을 해결하기 전에는 `enabled=true`로 바꾸지 않는다.

실행 프롬프트는 production-prompt.txt, 상태·차단 조건은 routine.json, 실제 등록 응답은 registration-response.json에 보관한다. 모의 테스트나 비공개 업로드 성공을 완전 무인 제작·공개의 증거로 쓰지 않는다.

오늘 한국어 ep13은 업로드 완료. 영어 ep12는 11월 5일 업로드되어 오늘 제작분에 중복 집계하지 않는다. 추가 요청은 ep14에 기록한다.
