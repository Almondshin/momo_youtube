# 한국어 박수 챈트 완성곡

사용자는 “톡톡 통통” B 방향을 선택했다. B1을 기준으로 정한 것은 작업자 판단이며 사용자 개별 테이크 지명으로 기록하지 않는다.

- 참조: B1 `db1999ca-a499-4bfa-afa5-d903b742bfd9` (43.88초). B2보다 덜 빠른 발음이라는 자동 청취 결과를 참고했다.
- 목소리·박자·후렴은 B1의 실제 소리를 유지한다. 별도 아동 합창이나 새로운 악기를 추가하지 않는다.
- 단어는 사과·바나나 두 개. 톡톡·통통·짝짝짝은 박자와 동작 표현.
- 목표 완성 길이 60~120초, 선호 약 80~90초. 짧은 훅을 반복하며 중간 간주를 줄인다.
- 기준곡의 가사·박자 정렬을 확인한 다음 보컬 구간 말미에서 연장한다. 1회 연장 생성(예상 10크레딧)으로 반환된 후보 중 검토 결과가 나은 연장본 하나를 무료 결합한다.
- 완성곡은 사용자에게 실제 듣기 링크를 제공한다. 별도 WAV 다운로드 크레딧 확인은 도구의 실제 사전 응답을 따른다.
- 영상은 승인된 사과·바나나·춤·박수 클립을 재사용한다. 한국어 실제 가창 시각에 맞춰 재편집하므로 영어 완성본에 음원만 덮어씌우지 않는다. 신규 Higgsfield 생성 없음.
