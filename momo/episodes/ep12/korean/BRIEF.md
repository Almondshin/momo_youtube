# 모모타임 — 사과랑 바나나 (한국어 후속곡)

2026-11-05 사용자 요청: “한국노래도 만들어야겠지”. 앞서 영어 다음 한국어 제작을 요청했으며, 현재 요청으로 한국어 후속곡 제작을 재확인했다. 채널 기본 영어 설정을 바꾸지 않고 이 후속곡만 한국어로 제작한다.

- 대상: 2~4세. 학습 단어는 **사과·바나나** 2개. 쉬운 말, 재미와 흥겨움.
- 음악 기준: 사용자가 선택한 영어 C2. 짧고 분명한 반복 후렴, 통통 튀는 박자, 밝은 여성 보컬. 앞서 거절한 과장된 초고음 아기 목소리로 돌아가지 않는다.
- 제작 선택: 공식 Suno MCP의 커버 도구에 소유한 C2 전체곡을 참조하고 한국어 새 가사를 전달한다. 한국어 음절에 맞춰 프레이징을 조정한다. 원곡과 동일한 목소리·멜로디가 보장되는 것은 아니다.
- 새 곡을 완전히 처음부터 만드는 방법은 기존에 고른 느낌을 잃을 가능성이 있어 첫 시도에서 제외한다. 영어 가사의 기계적인 직역 대신 한국어로 따라 부르기 쉬운 말을 쓴다.
- 우선 후보 2개를 만들어 비교한다. 최종 곡 길이 목표 60~120초, 약 80~90초 선호. 후보가 짧거나 끝이 끊기면 시안으로 표시한다.
- 영상: ep12의 승인된 사과·바나나·춤·박수 소재 재사용. 신규 Higgsfield 생성은 계획하지 않는다. 단어 표시는 사과/바나나 한 개씩. 한국어 실제 가창 시각에 맞춰 편집하므로 영어 완성 MP4에 음원만 덮어씌우지 않는다.
- 음원 후보 선택은 사용자에게 듣기 링크를 제공한 뒤 받는다. WAV 다운로드가 별도 크레딧 확인을 요구하면 그 단계에서 실제 비용을 확인한다.
- 비용: Suno 생성 예상 1회 10크레딧(기존 동일 공식 도구 사용 이력 기준), 실제 사용량 전후 확인. 다운로드 미실행. 새 영상 생성 0크레딧.
- 기존 영어 원본·승인 내역·업로드 기록과 한국어 후보를 구분해 보존한다.
