# ep12 리듬 수정 — v5 짧은 후렴

사용자: “좀 더 리드미컬해야하는데 바나나차차, 아기 상어 몰라?”

v4의 단순한 과일·yum 반복도 사용자가 원한 리듬감에 못 미쳤다. 2~4세용이라는 이유로 템포와 선율을
지나치게 단순·느슨하게 만든 접근을 수정한다. 귀여운 음색만으로 성공을 판정하지 않는다.

## 이번 제작 선택

- 유아용 댄스 팝. 또렷한 킥·박수 백비트, 통통 튀는 당김음 베이스와 짧은 플럭 소리.
- 124 BPM은 제작자의 선택이며 참조곡의 실제 BPM이라고 주장하지 않는다.
- 한 번 듣고 몸을 움직일 수 있는 짧은 리듬을 우선한다. 과일 이름과 pop/bop이 묻고 답하듯 이어진다.
- 음절을 박자에 붙여 짧게 부르고, 같은 2마디 후렴 패턴을 반복한다. 긴 음이나 장식음을 얹지 않는다.
- 밝고 귀여운 어린 여자아이 음색을 계속 지향한다. 실제 음색과 리듬은 결과로 확인한다.
- 이전의 ‘같은 가사·리듬 유지’와 ‘조용한 장난감 반주’ 방향을 적용하지 않는다.
- 32초 목표의 시안이며 최종 곡이 아니다. 아직 정규 길이·영상으로 확대하지 않는다.

## 새 후렴

```
Apple, pop! Apple, pop!
Apple, apple, pop-pop-pop!
Banana, bop! Banana, bop!
Banana, banana, bop-bop-bop!
```

위 후렴을 같은 선율·리듬으로 두 번 부른다. pop/bop은 리듬 소리이며 학습 카드에 추가하지 않는다.
참조곡의 가사·멜로디·음원을 입력하지 않았다.
