## 비용

이미지 6장 **12** + 5초 영상 6개 **30** = 기본 **42 Higgsfield 크레딧**.
재생성 여유 20%를 포함한 예상 **50.4 / 한도 150**. `estimate_credits.py`로 실제 manifest 검사 완료.
사용한 Higgsfield 크레딧은 아직 **0**이다. Suno 누적 생성 90 + 다운로드 1은 별도이며, 다운로드 잔액은 19다.
