# ep12 짧은 후렴 시안 — 전체 음악 방향 재검토

사용자가 기존 후보들의 목소리·가사·리듬 모두 마음에 들지 않는다고 정정했다.
이전 가사와 박자를 유지하겠다는 접근은 철회했다. 아래는 정규 곡이 아닌 **20초 목표 후렴 시안**이다.

- 주제는 apple·banana 두 가지를 유지한다.
- clap/tap 명령 나열과 verse/chorus의 긴 구조를 걷어내고, 과일 이름과 yum의 짧은 패턴만 쓴다.
- 같은 작은 선율을 반복하고 반주는 장난감 피아노·부드러운 실로폰 정도로 단순하게 둔다.
- 맑고 높고 귀여운 어린 여자아이 음색을 계속 요청하되, 실제 생성 결과가 그 음색이라고 미리 단정하지 않는다.
- 정확한 멜로디와 리듬은 생성 결과로 확인한다. 구체적인 선율이 사용자에게 승인된 상태가 아니다.
- 이 시안의 반응이 확인되기 전에는 정규 길이 곡이나 영상으로 확대하지 않는다.

## 시안 가사

```
Apple! Yum, yum!
Apple! Yum, yum!
Banana! Yum, yum!
Banana! Yum, yum!

Apple! Banana!
Yum, yum, yum!
```

요청·결과는 `suno/v4-*`에 저장한다. 기존 전체곡 가사는 `lyrics.md`와 `suno/v1-lyrics.md`~`v3-lyrics.md`에 이력으로 남기며,
현재 채택된 정규곡 가사는 없다. 시안 생성도 Suno 크레딧을 쓰므로 실제 사용량을 별도 기록한다.
