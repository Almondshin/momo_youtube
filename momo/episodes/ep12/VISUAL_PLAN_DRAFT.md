# ep12 영상 소재 계획 — 다운로드 전 초안

**2026-11-05 수정:** 여성 보컬·반복 후렴의 v2 음원을 생성 중이다. 아래 v1 기준 시간표는 대체 예정이며 제작에 사용하지 않는다.
6개 소재 재사용·예산은 참고값이다. 새 가창에 맞춰 clap/tap 동작과 사과·바나나 화면을 다시 배치한다.

기준: 영어곡 후보 B, 원본 98.76초. 음원 편집 뒤 최종 컷 번호와 시작 시각을 확정한다.
이 문서는 기획 승인이나 생성 지시를 대신하지 않는다. 현재 `manifest.json`의 두 라이브러리 컷은 초기 자리표시자다.

승인된 모모 캐릭터 시트를 직접 확인했다. 크림색 털, 큰 눈, 처진 귀, 민트 멜빵과 노란 단추 두 개를 유지한다.
기존 캐릭터 시트·라이브러리는 재생성하지 않는다. 밝은 놀이방, 낮은 둥근 탁자와 파스텔 배경을 공통으로 쓴다.

| 소재 | 화면 | 작은 움직임 | 주 사용 구간 |
|---|---|---|---|
| A1 | 모모와 탁자 위 빨간 사과 하나. 정면에 가까운 구도, 양쪽 단추 보임 | 한 손으로 사과 가리키기, 눈 깜박임 | 사과 소개·복습 |
| A2 | 같은 사과 하나의 가까운 화면, 사물의 모양이 또렷함 | 사과는 고정, 은은한 빛 변화만 | APPLE 반복 |
| B1 | A1과 같은 배경·구도, 탁자 위 노란 바나나 하나 | 바나나 가리키기, 작은 고개 끄덕임 | 바나나 소개·복습 |
| B2 | 같은 바나나 하나의 가까운 화면 | 바나나는 고정, 은은한 빛 변화만 | BANANA 반복 |
| C1 | 모모가 양발을 바닥에 둔 채 서 있는 중간 거리 화면 | 작은 좌우 몸 흔들기 | Sing along with me |
| C2 | 같은 모모, 양손과 두 단추가 잘 보이는 정면 구도 | 느린 박수, 작은 귀 흔들림 | Sing and clap with me |

- 6장의 시작 이미지와 각 5초 클립 6개를 만들고, 반복되는 가사에는 같은 클립을 재사용한다.
- 한 화면에는 사과 또는 바나나 한 종류만 보인다. 과일을 들고 뛰거나 먹는 동작은 없다.
- 카메라는 고정한다. 입 모양은 노래에 맞추지 않는다. 한국어 곡에도 쓸 수 있는 공통 소재다.
- 승인된 `intro_wave`·`outro_bye`는 시작·끝 길이가 맞을 때 영상만 사용한다. Suno 가창 위에 고정 나레이션을 겹치지 않는다.
- APPLE 또는 BANANA만 한 번에 하나 표시한다. 생성 이미지에는 글자를 넣지 않는다.
- 기존 조립기는 노래 전체 가사 자막이 기본이다. 최종 조립 전 핵심 단어만 나오는지 별도로 확인해야 한다.
  이 초안 작성 시점에는 자막 동작을 바꾸지 않았다.
