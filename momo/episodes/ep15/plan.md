# ep15 한국어판 제작 계획

사용자의 “한국어도 가야지” 요청으로 ep14 동물 주제를 한국어 원곡으로 만든다. “고양이·강아지” 두 단어와 “야옹·멍멍”, 짧은 박수 후렴을 사용한다.

## 음악

후보 1: 73.96초, 122.1 BPM. 후보 2: 74.76초, 120.1 BPM. 둘 다 기본 Suno v6 생성 한 번에서 나왔으며 합계 10 생성 크레딧을 사용했다. 담당자는 짧은 마무리의 1번을 추천한다. 선택과 다운로드 1크레딧 확인 응답을 기다린다. 확정 후 실제 WAV 보컬과 가사 시점을 대조하며 정확한 컷 길이를 정한다.

## 영상

| 원본 | 용도 | 비용 |
|---|---|---:|
| ep14/c02 모모·고양이 | 고양이 이름이 나오는 구간 | 0 |
| ep14/c04 고양이 가까이 | 야옹 반복 구간 | 0 |
| ep14/c03 모모·강아지 | 강아지 이름이 나오는 구간 | 0 |
| ep14/c05 강아지 가까이 | 멍멍 반복 구간 | 0 |
| ep14/c16 모모 박수 | 짝짝 반복 구간 | 0 |
| ep14/c01 모모 춤 | 짧은 도입·전환 구간 | 0 |

모든 원본은 승인·검수된 것을 그대로 사용한다. 립싱크는 하지 않는다. 동물 화면에만 고양이 또는 강아지 한 단어씩 표시하며, 모모 단독 화면에는 단어를 붙이지 않는다. 한 컷을 원본 5.04초보다 길게 늘이거나 끝 프레임에서 멈추지 않는다. 목표 길이는 1~2분, 현재 두 후보는 약 74초다.
