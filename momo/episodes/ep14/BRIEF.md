# ep14 — Cat, Cat! Dog, Dog!

2026-11-06 금요일 추가 영어 동요. 2~4세 아이가 두 단어 CAT·DOG를 배우고 짧은 후렴을 따라 부르는 콘텐츠다. 모모타임 한 채널에 올리며 영어 재생목록을 사용한다.

사용자가 기준곡 A를 80%로 평가하고 “리듬·후렴을 더 신나고 중독성 있게”, “따라하기 쉽게”를 요청했다. 원곡을 참조한 수정본 두 개 중 수정 1번(77.28초)을 선택했다. 공식 Suno MCP로 WAV를 다운로드했고 원본과 보컬·반주 스템을 보존했다. 기준곡과 수정 2번도 기록을 유지한다.

영상은 모모·고양이, 고양이 가까이, 모모·강아지, 강아지 가까이 네 원본 장면을 새로 만들고 승인된 기존 모모 춤·박수를 재사용했다. 립싱크 없음. 동물이 나오는 화면에만 CAT·DOG 한 단어를 표시하며 모모 단독 화면에는 단어를 붙이지 않는다. 37개 짧은 재생 컷으로 77.27초 전체 영상 완성.

사용자가 33.6크레딧 영상 예산을 승인했고 실제 Higgsfield 비용은 28크레딧(이미지 4장·클립 4개), 재생성은 없다. 이 에피소드의 Suno 곡 생성은 앞선 두 요청 합계 20크레딧, 선택곡 WAV 다운로드 1크레딧이다.

반복 의성어 때문에 두 로컬 음성인식 모델이 전체 가사를 정확히 검증하지 못했다. 사용자에게 실제 수치를 보고했고 “항상 지침을 따르지 않아도돼”라는 진행 지시를 받았다. 95% 자동 인식 통과라고 주장하지 않는다. 공식 단어 정렬과 보컬 발성점을 대조해 키워드 시점을 정하고, 모든 원본 클립과 완성본의 화면을 담당자가 검토했다. 자세한 증거는 manifest와 qa-report.json에 있다.
