# assets/bgm — 배경음악

**로열티 프리 키즈 BGM 루프** 파일을 넣는다 (wav / mp3 / m4a / aac / ogg / flac / opus).

## 고르는 기준

- 밝고 단순한 악기곡, 보컬 없음 (나레이션과 겹치지 않게). 2~5세용이라 급격한 음량 변화·놀라는 소리 없는 곡.
- 30초~2분 길이의 끊김 없는 루프면 좋다 (영상 길이만큼 반복하고 이음새는 짧게 크로스페이드한다).
- 음량은 신경 쓰지 않아도 된다 — 조립 때 `bgm_gain_db`(-12dB), 나레이션 구간 -16dB 덕킹, 시작·끝 페이드,
  최종 -14 LUFS 정규화를 한다.

## 라이선스 (중요)

- YouTube 업로드·수익화에 쓸 수 있는 라이선스여야 한다. 출처 표기가 필요하면 업로드 설명에 넣는다.
- **Content ID 에 등록된 곡은 피한다** — 저작권 클레임이 걸려 수익이 곡 주인에게 간다.
- 라이선스·출처를 같은 이름의 텍스트 파일로 옆에 둔다 (예: `happy_loop.mp3` + `happy_loop.LICENSE.txt`).
  음악 파일만 BGM 으로 인식하므로 텍스트 파일은 무시된다.
- 예: YouTube 오디오 보관함(Studio → 오디오 보관함)의 곡 — 곡마다 출처 표기 조건이 다르니 확인.

## 어떻게 쓰이나

선택 순서: `manifest.bgm`(파일명) → `config.audio.bgm_file` → 이 폴더의 첫 파일(이름순).
에피소드마다 다른 곡을 쓰려면 여러 개 넣고 manifest 의 `bgm` 에 파일명을 적는다.

**BGM 이 없으면 파이프라인이 멈춘다** — `doctor.py` ✖, build.py 는 "assets/bgm/ 에 BGM 을 넣어줘" 에러.
(`build.py --allow-missing` 애니매틱만 BGM 없이 만든다.)
