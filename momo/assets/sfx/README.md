# assets/sfx — 효과음 (선택)

없어도 파이프라인은 돌아간다. 넣으면 manifest 가 지정한 위치에 섞인다.

## 넣을 만한 것

| 파일 예 | 쓰임 |
|---|---|
| `pop.wav` | 키워드 등장, 사물 등장 |
| `whoosh.wav` | 장면 전환. **이름에 `whoosh` 나 `transition` 이 들어간 파일**은 compile.py 가 모음집의 에피소드 사이 전환 클립에 자동으로 얹는다 |
| `ding.wav` | 정답·칭찬 ("Great job!") |
| `boing.wav` | 깡충 뛰기 |

- 짧고(1.5초 이하) 부드러운 소리. 2~5세가 놀랄 만한 큰 소리·날카로운 소리는 쓰지 않는다.
- 로열티 프리이고 YouTube 에 쓸 수 있는 라이선스인지 확인하고, 라이선스 파일을 옆에 둔다 (예: `pop.LICENSE.txt`).

## manifest 에서 쓰는 법

```json
"sfx": [{"file": "pop.wav", "at": 0.5, "gain_db": -6}]
```

- `file`: 이 폴더의 파일 이름 (확장자가 달라도 같은 이름이면 찾는다), `at`: 컷 시작 기준 초, `gain_db`: 음량 (기본 -6).
- 파일이 없으면 경고만 하고 그 효과음은 생략한다.
