## 공식 경로 확인

Suno는 2026-10-28 공식 MCP 베타를 발표했다. 공식 서버 주소는
`https://api.suno.com/mcp`이며, Suno 계정 로그인·접근 동의 방식으로 연결한다.
공식 안내에 따르면 별도 API 키가 필요 없고 기존 Suno 플랜의 크레딧을 사용하며 곡은 Suno 라이브러리에 저장된다.
공식 안내는 모든 플랜을 지원한다고 하지만, 베타 접근 신청 경로가 있다. 이 계정은 11월 4일에는
접근이 거부되었고, 11월 5일 승인 메일 및 실제 연결 성공을 확인했다.
유료 구독 여부만으로 MCP 접근 가능성을 단정하지 않는다.

출처:

- [Suno MCP](https://suno.com/mcp)
- [2026-10-28 공식 발표](https://suno.com/release-notes/suno-mcp-beta)
- [연결 절차](https://help.suno.com/en/articles/14551425)
- [MCP FAQ](https://help.suno.com/en/articles/14486145)

이 경로는 저장소가 금지하는 비공식 Suno MCP·브라우저 생성 자동화와 구별한다.
기존 문서의 ‘공식 API가 없어 연동 경로가 없다’는 전제로 공식 MCP까지 불가능하다고 안내한 것은 정정한다.
음원 원본·스템 확보, 가사 정렬, 품질 검사와 제작 예산 규칙은 계속 적용한다.

## 2026-11-04 최초 등록 이력

1. 플러그인 검색 도구의 `Suno` 검색 결과는 0개였다. 이 결과는 공식 MCP가 없다는 뜻이 아니다.
   검색 결과가 전체 목록은 아니므로 [플러그인 디렉터리](https://chatgpt.com/plugins)에 다른 항목이 있을 수 있다.
2. 기존 로컬 Codex 설정에 `suno` 항목이 없는 것을 확인한 뒤, 설치된 Codex CLI로 등록했다.

   ```bash
   codex mcp add suno --url https://api.suno.com/mcp
   ```

   응답: `Added global MCP server 'suno'.`

3. CLI가 OAuth 지원을 감지해 계정 인증 절차를 시작했다. 서버 설정은 로컬 Codex 사용자 설정
   `~/.codex/config.toml`에 저장되었다. 계정 비밀값을 저장소나 문서에 복사하지 않았다.
4. 사용자 제공 인증 화면에서 다음 오류를 확인했다.

   > 계정 연결 오류
   > 계정에서 아직 AI 앱을 Suno에 연결할 수 없습니다.

5. 계정 접근이 거부되었으므로 대기 중인 OAuth 프로세스를 종료했다. 같은 로그인을 반복하지 않았고
   생성 요청·추가 결제·플랜 변경을 하지 않았다. 서버 설정은 재개를 위해 유지했다.

당시에는 설정만 저장되었으며 계정 인증은 미완료였다. 11월 5일 인증·도구·크레딧 조회까지 해결했다.

## 다음 조치

공식 MCP 페이지와 릴리스 노트의 **Get early access**가 연결하는
[Suno MCP Early Access Form](https://sunomusic.typeform.com/to/JMPYxZqQ)에서 베타 접근을 신청할 수 있다.
사용자가 신청을 완료했고 승인 안내와 실제 연결을 확인했으므로 다시 신청할 필요가 없다.

현재 인증은 완료되었다. 이후 인증이 만료되거나 연결에서 재인증을 요구하는 경우에만 다음 명령을 사용한다.

```bash
codex mcp login suno
```

아래 1~4번은 연결 확인과 ep12 실제 생성으로 검증했다. 5번은 다운로드 확인부터 이어서 검증한다.

1. OAuth 완료와 실제 Suno 도구 연결. 필요하면 현재 클라이언트의 MCP 설정을 새로 읽는다.
2. 계정 플랜·크레딧과 생성 도구가 받는 실제 입력. 호출 명칭이나 매개변수는 임의로 추측하지 않는다.
3. ep12의 [가사·스타일](../episodes/ep12/lyrics.md)로 승인된 범위의 음악 생성.
4. 반환된 작업 ID·상태·실제 비용·곡 ID·음원 주소 기록. 결과 불명 상태에서 중복 제출하지 않는다.
5. 음원 다운로드 형식, 스템 지원 여부, 토큰 갱신, Mac 예약 작업에서의 무인 실행 가능 여부.

계정 연결이 되더라도 5번까지 검증하기 전에는 전체 제작 자동화나 예약 운영 완료로 표시하지 않는다.

도구 사용 시에는 실제 도구 설명과 플랜 권한을 따른다. `audio-download`는 먼저 `confirm` 없이 호출하며,
`requires_credit` 응답이 오면 사용자에게 해당 다운로드 크레딧 사용 승인을 받은 뒤에만 `confirm: true`로 호출한다.
`max_mode`는 사용자가 Max Mode를 명시적으로 요청한 곡에만 적용한다.
